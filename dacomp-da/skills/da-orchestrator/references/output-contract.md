# Output Contract (Rubric-Absent)

## Required Sections
1. Executive Summary
- Direct answer
- 2–3 key findings
- 1–2 actions with KPIs

2. Methods
- Data scope (tables/time window/filters)
- Metric definitions
- Aggregation logic
- Statistical methods (if any)

3. Results (by Requirement)
- KPI tables or computed metrics
- Comparison or ranking outputs
- Trend/relationship evidence

4. Recommendations
- Action → KPI mapping
- Monitoring plan

5. Limitations
- Data gaps
- Method assumptions

## Minimum Evidence Rules
- One table or metric output per requirement.
- One explicit numeric anchor per key conclusion.
- If no numeric evidence exists, avoid strong claims.
