# Output Contract (Generic, High-Score Friendly)

## Required Sections
1. Executive Summary
- Direct answer
- 2–3 key findings with numeric anchors
- 1–2 actions with KPIs

2. Methods
- Data scope (tables/time window/filters)
- Metric definitions + units
- Aggregation logic
- Statistical methods (if any)

3. Results (by Requirement)
- KPI tables or computed metrics
- Comparison or ranking outputs
- Trend/relationship evidence
- For threshold tasks: include count and percentage.
- For ranking tasks: include top/bottom and min/max.
- For score tasks: include the exact formula and one worked example.

4. Recommendations
- Action → KPI mapping
- Monitoring plan

5. Limitations
- Data gaps
- Method assumptions

## Minimum Evidence Rules
- One table or metric output per requirement.
- One explicit numeric anchor per key conclusion.
- If thresholds exist, report counts and percentages.
- If ranking/segmentation exists, report top/bottom and min/max.

## Quality Gate (Before Final Output)
- Completeness: every requirement in the task contract has a corresponding result block.
- Accuracy: formulas, units, thresholds, and boundaries are unchanged from the task contract.
- Conclusion: each recommendation references at least one numeric anchor from Results.
- Coverage Matrix: include a requirement-level pass/fail checklist during drafting; do not finalize until all rows pass.
