# Path Selection Table

| Scenario | Choose This Path Type | Rationale |
|---|---|---|
| Rubric lists multiple Paths per Requirement | Exact matching Path | Scoring depends on matching Path steps |
| Path has anchors/pseudo-code | Anchor/Pseudo-code Path | Required for accuracy scoring |
| Data missing for preferred Path | Alternate Path with available fields | Avoid zero scores due to missing evidence |
