# exp-da-008 Final Report Hardening Checklist

## When to use
- You are ready to write `stage1.md` and terminate.
- The analysis includes multiple metrics, segments, and recommendations.
- You need to maximize rubric completeness and readability.

## Experience
Before finalizing, run this checklist:
1. Every requirement has explicit answer sentence(s), not implied.
2. All critical numbers include context (`n`, `%`, unit, comparison baseline).
3. Root cause statements cite at least one quantitative evidence line.
4. Each recommendation links to a diagnosed cause and has measurable target.
5. Add a short "Limitations/Assumptions" block if data constraints exist.

## Compact section structure
- Executive summary (3-5 bullets)
- Requirement-by-requirement findings
- Root-cause synthesis
- Action plan with targets
- Assumptions/limitations

## Common failure prevented
- Good analysis but weak final packaging that loses rubric points.
