# exp-da-032 Explicitly Map Rubric Requirements to Analysis Steps

## Experience
*   Before writing any code, parse the task and create a table mapping each rubric requirement/deliverable to specific analysis steps and output metrics.
*   For each step, identify the exact data columns, transformations, and calculations needed to produce the required numbers.
*   Continuously cross-reference your intermediate outputs against this map to ensure each requirement is being addressed with evidence.
*   At the conclusion, validate each requirement's output against the rubric's anchor numbers or expected format before finalizing the report.

## Checklist
- List all explicit and implicit task requirements
- Define the precise SQL query or calculation for each required metric
- Verify output sample sizes and alignment with anchor values
- Add a final compliance check before delivering

## Common failure prevented
Producing a generic analysis that misses specific, graded rubric points, leading to a low score.
