# exp-da-011 Path Minimum Output Contract

## Experience
After selecting a path, lock a minimum output contract per requirement:
1. Target segment definition (rule + count + proportion).
2. Core comparison table (at least one target-vs-control view).
3. Driver evidence (one numeric effect for each claimed driver).
4. Action plan (owner, target, timeline, guardrail).

## Minimal output
- A 4-line checklist per requirement and all boxes checked before terminate.

## Common failure prevented
- Incomplete answers despite correct partial analysis.
