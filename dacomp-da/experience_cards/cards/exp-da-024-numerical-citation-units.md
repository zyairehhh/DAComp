# exp-da-024 Numerical Citation and Units

## Experience
Report key numbers with units and source so that rubrics can verify correctness.
1. For every main metric, give: value + unit (e.g. "32.5%", "1.2M USD") and where it comes from (e.g. "from Table X", "query on table Y").
2. Avoid vague wording ("increased", "higher") without the actual before/after or magnitude.
3. When comparing groups or time periods, report at least two numbers (e.g. "Group A: 40%, Group B: 25%").
4. Percentages: state the base (e.g. "15% of total sales" or "15% of the 200 respondents").

## Checklist
- Key results → number + unit + source.
- Comparisons → both sides of the comparison stated.
- Percentages → base or denominator clear.

## Common failure prevented
- Accuracy deductions for unverifiable or ambiguous numbers.
- Completeness deductions when the report omits required numerical deliverables.
