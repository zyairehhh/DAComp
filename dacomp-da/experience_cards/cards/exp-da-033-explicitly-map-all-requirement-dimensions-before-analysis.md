# exp-da-033 Explicitly Map All Requirement Dimensions Before Analysis

## Experience
- **Extract all explicit and implied dimensions** from the task (e.g., vehicle type, rating, time period, location).
- **Create an analysis matrix or ledger** linking each dimension to required metrics and planned queries.
- **Design specific analytical steps** (e.g., time bands, distance bins, location clusters) for each dimension before coding.
- **Plan and execute joint analyses** (e.g., cross-tabulations) for any implied combinations of dimensions.
- **Check off each dimension in the ledger** during analysis to ensure full coverage before final reporting.

## Checklist
- List every dimension mentioned or implied in the task
- Map each dimension to a specific metric and analysis step
- Design queries for both single-dimension and multi-dimension (joint) analysis
- Verify all dimensions are addressed with evidence before finalizing

## Common failure prevented
Producing an incomplete strategy or analysis because key dimensions (e.g., time, location) were ignored or not jointly analyzed.
