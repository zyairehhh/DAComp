# exp-da-022 Evidence–Conclusion Link

## Experience
Rubrics penalize conclusions that are not backed by specific evidence. For every finding or recommendation:
1. Cite the exact number, table, or figure that supports it (e.g. "Table 2 shows X%; therefore …").
2. Do not state "X is higher" without giving the compared values and source.
3. Map each deliverable in the task to a dedicated subsection with at least one concrete number or reference.
4. If the data does not support a conclusion, say so explicitly instead of asserting.

## Checklist
- Each conclusion sentence → which number/table supports it?
- Each recommendation → which analysis or metric justifies it?
- No standalone "we recommend" without a preceding "because [evidence]".

## Common failure prevented
- Accuracy/completeness deductions for unsupported or vague conclusions.
- Conclusiveness deductions when the reader cannot verify the claim from the report.
