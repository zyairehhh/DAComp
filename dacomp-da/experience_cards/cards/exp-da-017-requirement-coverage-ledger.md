# exp-da-017 Requirement Coverage Ledger

## Experience
Build a requirement ledger before writing the final report:
- Parse each explicit deliverable into a checklist item.
- For each item, pre-assign: method, metric output, and conclusion sentence.
- Do a final pass ensuring every item has all three: result value, interpretation, action implication.

Do not submit if any checklist item lacks numeric output or actionable conclusion.

## Minimal output
- A short "Requirement Coverage" block mapping `Req -> evidence location` in report sections.

## Common failure prevented
- Completeness leakage (one or two missing deliverables causing path fallback).
