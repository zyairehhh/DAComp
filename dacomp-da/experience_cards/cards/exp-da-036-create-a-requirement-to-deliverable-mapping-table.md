# exp-da-036 Create a Requirement-to-Deliverable Mapping Table

## Experience
- **Parse the prompt and extract every distinct requirement, deliverable, and sub-criterion** into a list.
- **Create a mapping table** with columns: Requirement, Expected Output, Analysis Step, Evidence Location.
- **During analysis, systematically check off** each item as you produce the corresponding evidence and conclusion.
- **Structure the final report with clear headers** that correspond to each requirement or deliverable.
- **Before finalizing, validate** that every requirement is addressed with explicit evidence and a clear, direct answer.

## Checklist
- Decompose the prompt into explicit and implicit requirements
- Create a tracker mapping each requirement to a concrete output and analysis step
- Use the tracker during analysis to ensure coverage
- Label report sections with the requirement they address
- Perform a final completeness check against the tracker

## Common failure prevented
Missing specific sub-requirements or deliverables because they were not explicitly tracked, leading to incomplete answers and low rubric scores.
