# exp-da-001 Explicitly map task requirements to rubric-defined dimensions

## Experience
- Before analysis, parse the task description and rubric to extract a list of all required deliverables and evaluation dimensions (e.g., 'abnormal frequency', 'risk intensity', 'channel weight allocation').
- Create a mapping table linking each requirement to specific data fields, formulas, or analysis steps.
- Verify data availability for each mapped item, and document any assumptions or limitations if data is missing.
- Structure your analysis and final report to directly address each requirement, using clear section headers that map back to the rubric.
- If a rubric defines standard analysis paths, follow them exactly; if deviating, explicitly justify the choice.

## Checklist
- Extract a checklist of required deliverables from the task/rubric
- Map each requirement to data sources and calculation logic
- Check data availability and note assumptions early
- Structure the final output with sections for each requirement
- Adhere to rubric-defined analysis paths or justify deviations

## Common failure prevented
Prevents missing entire sections of required analysis by failing to connect task language to specific rubric criteria, leading to incomplete work.
