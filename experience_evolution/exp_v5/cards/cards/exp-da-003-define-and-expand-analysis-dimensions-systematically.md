# exp-da-003 Define and expand analysis dimensions systematically

## Experience
* **Step 1:** Extract the target metric and any explicitly mentioned dimensions from the task.
* **Step 2:** Systematically brainstorm and list all other relevant dimensions present in the data (e.g., time, location, user segments, product features).
* **Step 3:** For text fields (e.g., job descriptions), extract multidimensional qualities (skills, certificates) using pre-defined keyword categories.
* **Step 4:** Prioritize dimensions that allow for meaningful segmentation (peak/off-peak, high/low risk) or reveal interaction effects.
* **Step 5:** Plan analyses that test combinations of dimensions (e.g., fare by vehicle type AND hour of day) to uncover deeper insights.

## Checklist
- List all data columns and extracted text qualities that could influence the target
- Plan joint analyses (e.g., vehicle x time, skill x outcome)
- Schedule time-based and location-based segmentation

## Common failure prevented
Missing crucial insights by only analyzing the one or two dimensions directly mentioned in the request.
