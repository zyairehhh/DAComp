# exp-da-004 Formalize hypothesis testing for comparative analyses

## Experience
* **Step 1:** Define the null and alternative hypotheses in writing before running any analysis.
* **Step 2:** Select the correct statistical test (e.g., ANOVA for means of ≥2 independent groups) and justify its use.
* **Step 3:** Check test assumptions (normality, homogeneity of variances) and document the results.
* **Step 4:** Report full results: test statistic, degrees of freedom, p-value, and effect size. State whether the null hypothesis is rejected.
* **Step 5:** If the omnibus test is significant, conduct post-hoc pairwise comparisons with appropriate correction (e.g., Tukey's HSD).
* **Step 6:** Annotate every comparative claim (e.g., 'Group A is highest') with the supporting statistical evidence.

## Checklist
- State the null and alternative hypotheses for each comparative question
- Select and justify the use of ANOVA, t-test, or non-parametric equivalent
- Report the test statistic, df, p-value, and effect size
- Perform post-hoc tests if the omnibus test is significant
- Annotate every comparative claim with statistical evidence

## Common failure prevented
Making comparative claims (e.g., 'Level 5 has the highest risk') without statistical significance testing, leading to rubric failure on analysis depth.
