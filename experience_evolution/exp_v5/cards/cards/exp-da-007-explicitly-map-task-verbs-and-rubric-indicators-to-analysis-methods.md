# exp-da-007 Explicitly map task verbs and rubric indicators to analysis methods

## Experience
* **Step 1:** Translate task verbs (e.g., 'analyze factors', 'identify drivers') into a requirement for multivariate analysis (e.g., regression), not just group-by averages.
* **Step 2:** Scrutinize the task/rubric for explicitly defined indicator names and formulas (e.g., 'Two-Factor Authentication Not Enabled Rate').
* **Step 3:** Create a checklist of required indicators and analysis methods before querying data.
* **Step 4:** Calculate each required indicator exactly as defined, using the specified formulas. Do not substitute your own derived metrics unless allowed.
* **Step 5:** For multivariate analysis, select an appropriate model, report coefficients and significance, and rank factors by influence.
* **Step 6:** Anchor conclusions and recommendations primarily on these pre-defined indicators and model outputs.

## Checklist
- List required indicators and their exact formulas from the task/rubric
- Confirm multivariate analysis is needed and choose appropriate method (e.g., regression)
- Calculate required indicators using exact formulas and report model outputs
- Link all conclusions to specific, calculated data points from the required analysis

## Common failure prevented
Performing only univariate analysis when multivariate is required, or creating valid but irrelevant analysis that misses rubric-specified scoring dimensions.
