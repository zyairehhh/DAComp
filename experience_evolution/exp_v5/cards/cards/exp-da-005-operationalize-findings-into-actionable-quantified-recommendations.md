# exp-da-005 Operationalize findings into actionable, quantified recommendations

## Experience
* **Step 1:** Structure recommendations in a clear framework (e.g., a matrix with scenarios as rows and action components as columns).
* **Step 2:** For each action, define a **quantitative target** (e.g., 'reduce error rate to below 10%') and a **clear timeframe** (e.g., 'within 1 month').
* **Step 3:** Define explicit **trigger thresholds** for actions based on analysis (e.g., 'Activate plan if Risk Score > 7').
* **Step 4:** Include a **priority rule** for ranking or allocating resources, with a concrete application example.
* **Step 5:** Link every recommendation directly to a specific analytical result, citing the evidence (e.g., 'Because ANOVA showed...').

## Checklist
- Build a scenario × action matrix (e.g., a RACI or action table)
- Define numeric targets and deadlines for each action (SMART goals)
- Create a clear priority rule with an allocation example
- Cite analysis evidence for each recommended action

## Common failure prevented
Providing vague, non-operational recommendations without explicit triggers or a structured format, failing to meet rubric requirements for actionable output.
