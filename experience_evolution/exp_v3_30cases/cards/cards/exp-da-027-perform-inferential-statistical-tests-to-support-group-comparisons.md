# exp-da-027 Perform inferential statistical tests to support group comparisons

## Experience
- For comparing more than two groups (e.g., project types, risk levels), run an ANOVA if assumptions (normality, homogeneity of variance) are met; otherwise, use the Kruskal-Wallis test.
- If the omnibus test is significant (p < 0.05), conduct post-hoc pairwise comparisons (e.g., Tukey's HSD, Dunn's test with Bonferroni correction) to identify which specific groups differ.
- For each pairwise comparison, report p-value, confidence interval, and effect size (e.g., Cohen's d, Hedge's g) to quantify the magnitude of the difference.
- Do not rely solely on descriptive ranking of group means; always accompany ranking with statistical evidence.

## Checklist
- Conduct omnibus test (ANOVA/K-W)
- If significant, run post-hoc tests
- Report p-values, CIs, effect sizes
- Avoid ranking without significance

## Common failure prevented
Stating an order relationship (e.g., Medium > High > Low) without statistical evidence, leading to unsubstantiated conclusions.
