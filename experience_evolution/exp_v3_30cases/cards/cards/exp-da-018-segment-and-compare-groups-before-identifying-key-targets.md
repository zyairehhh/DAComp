# exp-da-018 Segment and compare groups before identifying key targets

## Experience
- Identify the segmentation dimensions mentioned (e.g., manufacturer, category, origin).
- Compute summary statistics (e.g., average, total, count) for your key metrics *within each segment*.
- Perform systematic comparisons (e.g., ranking, statistical tests) to highlight differences between segments.
- Only after segment analysis, drill down to identify specific high-risk or high-impact items within priority segments.
- Report both segment-level and item-level insights, stating which segments are higher priority and why.

## Checklist
- Identify all segmentation dimensions in the task
- Compute aggregate metrics per segment
- Rank or compare segments to find high-priority groups
- Then filter individual items within high-priority segments
- Report both segment-level and item-level insights

## Common failure prevented
Directly ranking individual items without first analyzing segment-level risk differences, missing the core requirement.
