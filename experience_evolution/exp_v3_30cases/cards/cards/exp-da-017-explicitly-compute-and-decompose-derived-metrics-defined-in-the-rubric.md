# exp-da-017 Explicitly compute and decompose derived metrics defined in the rubric

## Experience
- Before any analysis, parse the rubric or task instruction for explicit metric definitions (e.g., 'unit freight = Σ(Shipping Cost) ÷ Σ(Quantity)').
- Compute each required derived metric separately and verify its components are correctly aggregated.
- If a proxy or alternative metric is used, justify why the required metric could not be computed and document the substitution.
- Decompose derived metrics to understand their drivers (e.g., changes in unit freight can be due to changes in shipping cost mix vs. quantity mix).
- Compare the computed derived metric against simpler proxies (e.g., average shipping cost) to validate sensitivity.

## Checklist
- List required derived metrics from the rubric/task
- Compute each derived metric with the exact formula
- If data is unreliable, note it and use proxy with justification
- Document how the derived metric differs from a simple proxy
- Include derived metric in all diagnostic steps it is required for

## Common failure prevented
Missing the precise metric required for scoring, leading to rubric failures.
