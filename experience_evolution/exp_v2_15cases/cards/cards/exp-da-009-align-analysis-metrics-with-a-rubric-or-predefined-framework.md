# exp-da-009 Align analysis metrics with a rubric or predefined framework

## Experience
- At the start of analysis, explicitly list all required dimensions or metrics from the task description or rubric.
- Cross-reference your planned calculations with the required list, and flag any missing or mismatched metrics before proceeding.
- Do not substitute required metrics with your own derived or similar-looking metrics without explicit justification.
- If a required metric cannot be computed due to data limitations, explicitly state this limitation and adjust the analytical plan accordingly.
- Ensure your final analysis output includes every required metric and dimension specified.

## Checklist
- List required metrics from task/rubric
- Map each metric to a SQL query or calculation plan
- Verify output includes all required metrics before finalizing
- Document any metrics that cannot be computed

## Common failure prevented
Prevents scoring zero on rubric criteria because the agent's metrics do not match the explicitly required ones.
