# exp-da-002 Proactively analyze all key dimensions suggested by the task

## Experience
- Before starting, list all analysis dimensions mentioned or implied in the task (e.g., Vehicle Type, Driver Rating, time period, location).
- Define a specific, measurable analysis question for each dimension.
- Prioritize and schedule analyses for each dimension, starting with the most critical for the business question.
- Ensure at least basic descriptive statistics are computed for each key dimension.
- When reporting, explicitly state which dimensions were analyzed and which were not, with a brief justification.

## Checklist
- List all potential analysis dimensions from the task
- Define a measurable question for each dimension
- Schedule and perform at least basic analysis for each
- Document analysis coverage and exclusions

## Common failure prevented
Prevents missing entire analysis dimensions that were implied in the task but not explicitly required, leading to incomplete findings.
